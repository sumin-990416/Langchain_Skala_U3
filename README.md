# 배터리 분석 AI 스타트업 투자평가 Multi-Agent RAG

> LangGraph 기반 다중 에이전트(Multi-Agent)와 Agentic RAG를 활용하여, 배터리 분석 AI 스타트업의 문서를 수집/검증하고 5가지 서로 다른 투자 관점으로 병렬 평가하여 최종 투자 검토 보고서를 자동 생성하는 AI 파이프라인입니다.

## 🚀 주요 기능 및 구현 아키텍처

본 프로젝트는 단순한 직렬 평가를 넘어, **사실 분석과 투자 성향을 완벽히 분리**한 고도화된 아키텍처를 구현했습니다.

### 1. Data Ingestion & RAG
- **동적 기업 인식**: `data/raw/` 폴더에 위치한 기업의 공식 문서(PDF, TXT 등)를 자동으로 스캔하고 회사명을 추출합니다.
- **최적화된 임베딩**: 빠르고 정확한 다국어 임베딩을 위해 OpenAI `text-embedding-3-small` 모델을 사용합니다.
- **정밀한 청킹**: Chunk Size 500, Overlap 50으로 리트리버 단위를 최적화하여 정보 검색의 정확도와 속도를 극대화했습니다.

### 2. Multi-Agent 평가 파이프라인 (LangGraph)
1. **공통 도메인 평가 (`score_domains`)**: 검색된 사실(Evidence)을 바탕으로 기술, 시장, 재무, 리스크, 팀 5대 영역의 객관적 공통 점수를 계산합니다.
2. **Critical Risk Gate (`critical_risk_gate`)**: 치명적 결함이나 기준 점수 미달을 1차적으로 필터링하여, 통과(PASS) 시에만 다음 심층 평가로 넘깁니다.
3. **병렬 프로필 에이전트 (`profile_agent`)**: 5개의 서로 다른 투자 성향(기술중심형, 안정형, 성장형, 균형형, 사업성중심형)을 가진 에이전트가 **동일한 근거를 바탕으로 서로 다른 가중치를 적용해 병렬(동시) 평가**를 진행합니다.
4. **최종 의견 조율 (`synthesize`)**: 5개 에이전트의 점수와 의견 차이를 종합(Consensus)하여 최종 투자 판정과 요약 보고서를 작성합니다.

## 💻 설치 및 실행 방법

### 1. 환경 변수 설정
프로젝트 루트 경로에 `.env` 파일을 생성하고 OpenAI API 키를 입력합니다.
```env
OPENAI_API_KEY=sk-...
```

### 2. 분석 데이터 준비
평가하고자 하는 기업의 실제 문서(PDF, DOCX, TXT)를 `data/raw/` 폴더에 넣습니다. (예: `ACCURE_RAG_source_pack.pdf`)

### 3. 파이프라인 실행
터미널에서 아래 명령어를 실행하면, 문서 임베딩부터 그래프 구동, 최종 보고서 생성까지 전자동으로 진행됩니다.
```bash
uv run python main.py
```
